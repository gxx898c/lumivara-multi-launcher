# Lumivara Multi-Launcher

เล่นเกม [Lumivara Online](https://lumivaraonline.com/) หลายไอดีพร้อมกันบน Windows แต่ละจอเป็นหน้าต่างเกมแยกกัน และ **คุมทุกหน้าต่างจากหน้าเว็บเดียว** (`http://localhost:4321`)

## ทำอะไรได้บ้าง
- 🎮 **เปิดหลายจอพร้อมกัน** — เริ่มต้น 10 จอ กด **+ เพิ่มจอ / − ลดจอ** ได้ (สูงสุด 50) แต่ละจอเก็บข้อมูลล็อกอินแยกกัน (ล็อกอินคนละไอดีได้ รวมถึง Guest) ปิดแล้วเปิดใหม่ก็ยังล็อกอินอยู่
- 🏷 **ตั้งชื่อหน้าต่างเองได้ แก้ได้ทุกเมื่อ** แม้จอเปิดอยู่ — เช่น "AFK_01" เพื่อแยกจอใน taskbar ได้ง่าย
- 🖼 **PiP** — ย่อเกมเป็นหน้าต่างลอยเล็ก ๆ อยู่บนสุดเสมอ ย้าย/ย่อ–ขยายได้ถึง 64×48 พิกเซล ภาพเกมย่อให้พอดีโดยไม่โหลดเกมใหม่
- ⛶ **เต็มหน้าจอ** ทีละจอ
- 🙈 **ซ่อน / แสดง** — ซ่อนหน้าต่างหายไปจาก taskbar พร้อมปิดเสียง ทีละจอหรือทุกจอพร้อมกัน (`Ctrl+Shift+H` ใช้ได้แม้อยู่ในโปรแกรมอื่น)
- 🔇 **ปิดเสียง** ทีละจอ หรือทุกจอพร้อมกัน
- ▶ **เกมเล่นต่อแม้ย่อหรือซ่อนหน้าต่าง** — เหมาะกับปล่อย Auto Play / AFK หลายจอ
- 🩹 **กู้คืนเอง** — เกมแครช, ค้างเกิน 30 วินาที หรือเน็ตหลุด → จอนั้นโหลดเกมใหม่ให้เอง (ลองใหม่ทุก 10 วินาทีจนเน็ตกลับมา)
- 🔄 **รีเฟรชเกม** โดยไม่ต้องล็อกอินใหม่
- 🪟 **จัดเรียงทุกจอให้พอดีหน้าจอ** — กดปุ่มเดียวจัดทุกจอเป็นตาราง เลือกได้ว่าจะจัดบนจอภาพไหน (ถ้ามีหลายจอ)
- 📍 **จำตำแหน่งหน้าต่าง** — ปิดแล้วเปิดใหม่ หน้าต่างกลับมาที่เดิม ขนาดเดิม (ทั้งจอปกติและ PiP)
- ⏯ **เปิดจออัตโนมัติ** — ติ๊กจอที่ต้องการ แล้วจอเหล่านั้นจะเปิดเองทุกครั้งที่เปิด launcher (ใช้คู่กับเปิด launcher ตอนเข้า Windows = รีบูตแล้วกลับมา AFK ต่อเอง)
- 💾 **สำรองข้อมูลจอ** — กดปุ่มเดียวคัดลอกข้อมูลจอ (รวมข้อมูล Guest) ไปเก็บใน `backups\` ขนาดเล็กมาก (~1 MB) เพราะข้ามไฟล์แคช
- 📊 **ดู RAM / CPU** ของแต่ละจอและรวมทุกจอ
- 🔋 **ประหยัด CPU ตอนซ่อน** — จำกัดเฟรมเรตเกมของจอที่ซ่อนอยู่ได้ (ปกติหน้าต่างที่ซ่อนยังวาดเต็มรีเฟรชเรตจอ เช่น 144–180 FPS)
- 🔁 **เปิด launcher ใหม่เมื่อไรก็ได้** — ปิด launcher แล้วจอเกมยังเล่นต่อ เปิดกลับมาก็คุมจอเดิมต่อได้ ดับเบิลคลิกซ้ำตอนเปิดอยู่แล้วก็แค่เปิดหน้าเว็บให้
- 🔒 **ปลอดภัย** — รับคำสั่งเฉพาะจากเครื่องตัวเอง เว็บอื่นสั่งจอเกมไม่ได้ และไม่มีปุ่มล้างข้อมูลล็อกอิน (กันข้อมูล Guest หาย)

ฟีเจอร์หน้าต่างเกมยกมาจาก Lumivara Online Windows Client 4.4.5 แต่ย้ายปุ่มทั้งหมดจากในหน้าต่างเกมมาไว้ที่หน้าเว็บ

## เริ่มใช้งานเร็ว
1. ต้องมี [Node.js](https://nodejs.org) (เช็คด้วย `node -v`)
2. ดับเบิลคลิก **`Lumivara Launcher`** (shortcut ไอคอนเกม) → หน้าเว็บเปิดขึ้นมาเอง
3. พิมพ์ชื่อจอ กด **เปิด** แล้วล็อกอินเกมในหน้าต่างที่เปิดขึ้น

ติดตั้งใหม่ในเครื่องอื่นตั้งแต่ศูนย์: ดูขั้นตอนใน [CLAUDE.md](CLAUDE.md) (ส่งไฟล์นั้นให้ Claude Code สร้างโปรเจกต์ให้ได้เลย)

## โครงสร้าง
- `server.js` — ตัว launcher + API ของ web console ที่ `http://localhost:4321` (Node.js ไม่มี dependency)
- `public/` — หน้าเว็บ console: `index.html` (โครงหน้า), `style.css` (หน้าตา), `app.js` (การทำงานของปุ่ม)
- `client/` — โค้ดหน้าต่างเกม (Electron) จอที่ N ฟังคำสั่งจาก console ที่พอร์ต `4400+N` (เฉพาะในเครื่อง)
- `runtime/` — Electron runtime ที่คัดลอกมาจากโฟลเดอร์ `Lumivara-Online-Windows-x64` (ไม่รวม `resources\app.asar`) ตัวโปรแกรมเปลี่ยนชื่อเป็น `LumivaraClient.exe` และ `runtime\resources\app\package.json` ชี้ไปที่ `client\main.cjs`
- `saved/InstanceN/` — ข้อมูลโปรไฟล์และข้อมูลเข้าสู่ระบบของจอที่ N (สร้างอัตโนมัติตอนเปิดจอครั้งแรก ชื่อไม่เปลี่ยนตามชื่อจอ — ดูคู่ชื่อจอ↔โฟลเดอร์ได้ที่ป้าย 📁 ในหน้าเว็บ) มีไฟล์ `lv-window.json` เก็บตำแหน่งหน้าต่าง · โฟลเดอร์ `saved` ตั้งไว้ที่ "โฟลเดอร์ Instance" ใน ⚙ ตั้งค่า (`instancesDir`)
- `backups/` — ข้อมูลจอที่สำรองไว้ (`InstanceN-ปีเดือนวัน-เวลา`)
- `config.json` — ตำแหน่งตัวเกม (`exePath`), โฟลเดอร์ Instance (`instancesDir`), จำนวนจอ (`instanceCount`), ชื่อจอ (`titles`), จอที่เปิดอัตโนมัติ (`autoStart`), เฟรมเรตตอนซ่อน (`hiddenFps`, 0 = ไม่จำกัด), โฟลเดอร์ข้อมูลเฉพาะจอ (`dataDirs`), ลำดับแถว (`order`)
- `files.zip` (สำเนา launcher รุ่นเก่า) ไม่ได้ใช้แล้ว ลบได้

ถ้าย้ายโฟลเดอร์หรือสร้าง `runtime` ใหม่: คัดลอกโฟลเดอร์ `Lumivara-Online-Windows-x64` ทั้งหมดมาเป็น `runtime` ลบ `resources\app.asar` เปลี่ยนชื่อ exe เป็น `LumivaraClient.exe` แล้วสร้าง `resources\app\package.json`:

```json
{ "name": "lumivara-multi-client", "main": "../../../client/main.cjs" }
```

> ⚠ **อย่าลบโฟลเดอร์ข้อมูลจอใน `saved\`** — ถ้าเล่นแบบ Guest และยังไม่ผูก Google ข้อมูลหายแล้วจะกลับเข้าตัวละครเดิมไม่ได้ (โปรแกรมนี้จึงไม่มีปุ่มล้างข้อมูลเข้าสู่ระบบ) กด **สำรอง** เก็บไว้เป็นระยะจะปลอดภัยที่สุด

## ใช้งาน
เปิด launcher ด้วย **`Lumivara Launcher`** (ไม่มีหน้าต่าง cmd) หรือ `start.bat` (เห็น log/error) — ถ้าเปิดอยู่แล้ว ดับเบิลคลิกซ้ำจะแค่เปิดหน้าเว็บให้ (หรือเข้า `http://localhost:4321` เอง)

`Lumivara Launcher` เป็น shortcut ที่สั่ง `conhost.exe --headless node server.js` (เริ่มใน `E:\Lumivara`) จึงรัน node แบบไม่มีหน้าต่าง ไม่ต้องใช้ VBScript
- คัดลอก shortcut ไปวางที่ Desktop หรือคลิกขวา → ปักหมุดที่ Start/Taskbar ได้
- อยากให้เปิดเองตอนเข้า Windows: กด `Win+R` พิมพ์ `shell:startup` แล้ววางสำเนา shortcut ไว้ในโฟลเดอร์นั้น
- ถ้าย้ายโฟลเดอร์โปรเจกต์ ต้องแก้ "Start in" ของ shortcut (คลิกขวา → Properties) ให้เป็นโฟลเดอร์ใหม่ หรือสร้าง shortcut ใหม่: Target `C:\Windows\System32\conhost.exe --headless node server.js`, Start in = โฟลเดอร์โปรเจกต์, ไอคอน `client\game.ico`

### แต่ละแถว (หนึ่งแถว = หนึ่งจอ)
- **⋮⋮ ย้ายลำดับ** — ลากที่ ⋮⋮ เพื่อย้ายแถวขึ้น/ลง (หรือคลิก ⋮⋮ แล้วกด ↑ / ↓) ลำดับนี้ใช้กับ **จัดเรียงทุกจอ** และ **เปิดทั้งหมด** ด้วย · ย้ายได้แม้จอเปิดอยู่ · **ข้อมูลไม่ย้ายตาม**: จอที่ 2 ยังเป็นจอที่ 2 (โฟลเดอร์ข้อมูลเดิม ชื่อเดิม) แค่ไปอยู่ตำแหน่งอื่นในรายการ
- **ช่องชื่อ** — title ของหน้าต่างเกม พิมพ์แล้วกด Enter หรือคลิกที่อื่นเพื่อบันทึก (เก็บใน `config.json`) ถ้าจอเปิดอยู่ ชื่อหน้าต่างเปลี่ยนตามทันที
- **เปิด / ปิด** — เปิดหรือปิดจอนั้น
- **เรียก** ดึงหน้าต่างขึ้นมาด้านหน้า
- **PiP** สลับหน้าต่างลอยขนาดเล็กบนสุด (ลากแถบบนเพื่อย้าย ลากขอบเพื่อย่อ–ขยาย) / กลับจอปกติ
- **เต็มจอ** สลับเต็มหน้าจอ
- **ซ่อน / แสดง** ซ่อนหน้าต่างจาก taskbar พร้อมปิดเสียง (เกมยังเล่นต่อ) / เรียกกลับ
- **ปิดเสียง / เปิดเสียง** เฉพาะจอนั้น
- **รีเฟรช** โหลดหน้าเกมใหม่ (ไม่ล้างข้อมูลเข้าสู่ระบบ)
- **อัตโนมัติ** (ติ๊ก) — เปิดจอนี้ให้เองทุกครั้งที่เปิด launcher (จอที่เปิดอยู่แล้วจะไม่ถูกเปิดซ้ำ)
- **📁 InstanceN** — โฟลเดอร์ข้อมูลที่จอนี้ใช้ (ไม่เปลี่ยนตามชื่อจอ)
- **สำรอง** — คัดลอกข้อมูลจอนี้ไปที่ `backups\InstanceN-<วันเวลา>` (กดได้เฉพาะตอนจอปิดอยู่ กันไฟล์เสียระหว่างเกมกำลังเขียน) ไม่ลบอะไรทั้งนั้น
- ด้านขวาสุด: **RAM / CPU** ของจอนั้น และ **"กู้คืน N"** ถ้าจอเคยโหลดเกมใหม่เองเพราะแครช/ค้าง/เน็ตหลุด
- ปุ่มสีฟ้า = โหมดนั้นเปิดอยู่ · สถานะอัปเดตทุก 2 วินาที

**+ เพิ่มจอ / − ลดจอ** (ใต้รายการ) — เพิ่มหรือซ่อนแถวสุดท้าย (สูงสุด 50 จอ) การลดจอต้องปิดจอนั้นก่อน และ **ไม่ลบข้อมูล** — โฟลเดอร์ข้อมูล, ชื่อจอ และการตั้งค่ายังอยู่ กด + กลับมาก็ได้จอเดิม

ใต้รายการแสดง **จำนวนจอที่เปิด, RAM รวม, CPU รวม**

### ปุ่มด้านล่าง
- **เปิดเป็น PiP** (ติ๊ก) — จอที่เปิดหลังจากนี้จะเปิดมาเป็น PiP เลย
- **เปิดทั้งหมดที่ยังไม่เปิด** — เปิดทีละจอห่างกัน 0.5 วินาที
- **ตัวเลือกจอภาพ** (โชว์เมื่อมีมากกว่า 1 จอ และมีจอเกมเปิดอยู่) + **จัดเรียงทุกจอให้พอดีหน้าจอ** — จัดทุกจอที่แสดงอยู่เป็นตารางเต็มจอภาพที่เลือก เรียงตามเลขจอ เลือกจำนวนคอลัมน์ให้ภาพเกมใหญ่ที่สุด ออกจาก PiP/เต็มจอให้อัตโนมัติ (จอที่ซ่อนอยู่ไม่ถูกจัด)
- **ซ่อน / เรียกกลับทุกจอ** — เหมือน `Ctrl+Shift+H`
- **ปิด / เปิดเสียงทุกจอ** — ถ้ามีจอไหนยังมีเสียง จะปิดเสียงทุกจอ ไม่งั้นเปิดเสียงทุกจอ
- **ปิดทุกจอ**
- **ปิดโปรแกรมนี้ (launcher)** — ไม่ปิดจอเกม เปิด launcher ใหม่เมื่อไรก็เห็นและคุมจอที่เปิดอยู่ต่อได้ (การปิดแท็บเบราว์เซอร์อย่างเดียวไม่ได้ปิด launcher)

### คีย์ลัดในหน้าต่างเกม
| คีย์ | ทำอะไร |
|---|---|
| `Ctrl+Shift+P` | สลับ PiP / จอปกติ |
| `F11` หรือ `Alt+Enter` | สลับเต็มหน้าจอ |
| `Esc` | ออกจากเต็มจอ / กลับจาก PiP |
| `F5` | รีเฟรชเกม |
| `F8` | ซ่อนและปิดเสียงเฉพาะจอนี้ |
| `Ctrl+Shift+H` | ซ่อน / เรียกกลับทุกจอ (ใช้ได้แม้อยู่ในโปรแกรมอื่น) |

### 🤖 Automation (แถบข้างขวา)
กดปุ่ม **🤖 Automation** มุมขวาบนเพื่อเปิดแถบ (จำไว้ว่าเปิด/ปิดค้างไว้)
- **เลือกจอ** — ติ๊กจอที่ต้องการ (เรียงตามลำดับแถว แสดงชื่อจอ จุดเขียว = เปิดอยู่) หรือกด **ทั้งหมด / เฉพาะที่เปิด / ไม่เลือก** · จำการเลือกไว้ในเบราว์เซอร์
- **คำสั่ง** — **กด I** = กดปุ่ม I ในเกม 1 ครั้ง กับทุกจอที่เลือกและเปิดอยู่พร้อมกัน (ใช้ได้แม้จอซ่อนอยู่หรือไม่ได้โฟกัส) จอที่ปิดอยู่จะถูกข้าม แล้วแสดงสรุปผลใต้ปุ่ม
- การกดปุ่มส่งผ่าน DevTools ของหน้าเกม เกมเห็นเป็นการกดคีย์บอร์ดจริง · รับเฉพาะตัวอักษร ตัวเลข Space Enter Esc Tab และลูกศร (ไม่รันโค้ดอิสระ)
- ⚠ ระวังกฎของเกม: การใช้ automation เล่นแทน (บอท/ฟาร์มอัตโนมัติ) อาจทำให้โดนแบนได้ และไอดี Guest ที่โดนแบนจะกู้คืนไม่ได้

### ตั้งค่า (แถบ "⚙ ตั้งค่า")
- **ตำแหน่งตัวเกม / โฟลเดอร์ Instance** — path เต็ม หรือ path เทียบกับโฟลเดอร์ launcher มีผลกับการเปิดจอครั้งถัดไป
- **เฟรมเรตเกมตอนซ่อนหน้าต่าง** — ไม่จำกัด (ค่าเดิม) / 20 / 10 / 5 FPS มีผลทันทีกับทุกจอ ค่าต่ำประหยัด CPU มาก ถ้าตั้งแล้ว AFK สะดุดหรือเกมตามไม่ทัน ให้เพิ่มขึ้นหรือกลับไปไม่จำกัด

## ชื่อจอ ↔ โฟลเดอร์ข้อมูล
โฟลเดอร์ข้อมูลใช้ชื่อตามเลขจอเสมอ (`saved\InstanceN`) — การเปลี่ยนชื่อจอ **ไม่เปลี่ยนชื่อโฟลเดอร์** ดูว่าจอไหนใช้โฟลเดอร์ไหนได้ที่ป้าย **📁** ในแต่ละแถว เช่น `AFK_01 → 📁 Instance1`, `SAP → 📁 Instance6` (ชี้เมาส์เพื่อดู path เต็ม) ย้ายลำดับแถวด้วย ⋮⋮ ก็ไม่เปลี่ยนโฟลเดอร์

## สำรองและกู้คืนข้อมูลจอ
- สำรอง: ปิดจอ → กด **สำรอง** → ได้โฟลเดอร์ `backups\InstanceN-<วันเวลา>` (ดูจากป้าย 📁 ว่าจอไหนคือ InstanceN ไหน)
- กู้คืน (ทำเอง ไม่มีปุ่มเพื่อกันพลาด): ปิดจอนั้น → เปลี่ยนชื่อ `InstanceN` เดิมเป็นชื่ออื่นเก็บไว้ก่อน (อย่าลบ) → คัดลอกโฟลเดอร์ backup มาวางแล้วเปลี่ยนชื่อเป็น `InstanceN` → เปิดจอ
- ย้าย/เปลี่ยนชื่อโฟลเดอร์เองได้ ข้อมูลไม่หาย แต่ launcher หา `<โฟลเดอร์ Instance>\InstanceN` — ถ้าชื่อไม่ตรง จะได้จอใหม่ว่าง ๆ (ข้อมูลเดิมยังอยู่ในโฟลเดอร์ที่ย้ายไป) · ถ้าจำเป็นต้องใช้โฟลเดอร์อื่นจริง ๆ ตั้ง `dataDirs` ใน `config.json` ได้ เช่น `"dataDirs": { "6": "D:\\Lumivara\\SAP" }` (ปิด launcher ก่อนแก้ ไม่งั้น launcher จะเขียนทับ)

## แก้ปัญหา
- **ปุ่มใหม่ขึ้น "Not found" / ไม่ทำงาน** — launcher หรือจอเกมยังรันโค้ดเก่าอยู่ กด "ปิดโปรแกรมนี้" แล้วเปิด `Lumivara Launcher` ใหม่ ถ้าเป็นคำสั่งของหน้าต่างเกม (เช่น จัดเรียง, เปลี่ยนชื่อ) ให้ปิดจอแล้วเปิดใหม่ด้วย
- **"เปิดพอร์ตควบคุม 44xx ไม่ได้"** — มีโปรแกรมอื่นใช้พอร์ตนั้น เปลี่ยน `CONTROL_BASE_PORT` ใน `server.js`
- **กด Ctrl+Shift+H ไม่ได้ผล** — มีโปรแกรมอื่นจองคีย์นี้ไว้ ใช้ปุ่มในหน้าเว็บหรือ `F8` แทน
- **จอขึ้น "กู้คืน" บ่อย** — เน็ตไม่เสถียร หรือ RAM ไม่พอ (ดู RAM รวมใต้รายการ) ลองลดจำนวนจอ หรือจำกัดเฟรมเรตตอนซ่อน
- อยากดู error — เปิดผ่าน `start.bat` แทน `Lumivara Launcher`

## ปรับแต่ง (ใน `server.js` / `client/main.cjs`)
- `MAX_INSTANCES` จำนวนจอสูงสุดที่กด + ได้ (50)
- `PORT` พอร์ตหน้าเว็บ (4321)
- `CONTROL_BASE_PORT` พอร์ตควบคุมจอ (4400 → จอที่ N ใช้ 4400+N)
- `RETRY_MS` / `HANG_MS` ใน `client/main.cjs` — เวลารอก่อนลองโหลดใหม่ตอนเน็ตหลุด (10 วิ) / ถือว่าเกมค้าง (30 วิ)
